# Lab 3 - Modelo 3D

Modelo de una nave espacial low-poly realizado en Blender.

## Objetivo

Crear una nave espacial simple partiendo únicamente de un cubo y utilizando herramientas básicas de modelado.

## Herramientas utilizadas

- Move
- Scale
- Rotate
- Extrude
- Inset
- Bevel
- Knife
- Subdivide

No se agregan objetos adicionales al modelo principal. Toda la nave se construye modificando el cubo inicial.

## Archivos

- nave.blend - Archivo editable de Blender.
- nave.obj - Modelo exportado.
- nave.mtl - Material asociado al OBJ.
- preview.png - Captura final de la nave.

## Exportación

El modelo se exporta en formato OBJ con la geometría triangulada.

## Modelo

La nave utiliza un diseño low-poly compuesto por:

- cuerpo central;
- nariz;
- cabina;
- alas;
- motores;
- estabilizadores traseros.
